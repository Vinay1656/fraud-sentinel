# Product roadmap

The current deliverable is a working local screening pipeline. Product extensions are planned, not included in the current demo.

## Checkpoints

1. Publish the reproducible baseline, presentation, and CPU checks.
2. Agree on the extension scope and data plan.
3. Add sector-level risk views linked to an analyst investigation queue.
4. Add customer verification and analyst feedback as a local simulation.
5. Expand evaluation and training data, then document the measured outcome.

Each implemented checkpoint should be tested, documented, committed, and pushed before starting the next. Prefer one complete decision workflow over several disconnected demo screens.

Metrics work is paused at the user's request. It will resume as its own checkpoint.
